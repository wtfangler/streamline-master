Gain in the same scene: +34%

Content added: none

Optimization where Minecraft actually spends its time

Rendering, game logic, memory, chunk loading and networking each get a dedicated mod instead of one blunt "fps booster". Nothing here changes how the game plays.

Higher, steadier FPS

Sodium rebuilds the render pipeline, Lithium trims tick logic. The gain shows up as a flatter frame graph, not just a bigger number in F3.

Sodium, Lithium

Lower memory pressure

FerriteCore and ModernFix cut how much the game keeps in RAM. 3 GB is enough; 4 GB is a sensible ceiling on a laptop.

FerriteCore, ModernFix

Fewer stutters

Chunk work moves off the render thread and entity culling stops the GPU drawing what you cannot see. Exploring stops hitching.

C2ME, Entity Culling

Faster startup

ModernFix defers work the game does eagerly at launch, so both the client and world loading get out of the way sooner.

ModernFix

Better on servers

Krypton and Very Many Players reduce the cost of crowded worlds, so a busy spawn stops dragging the whole client down.

Krypton, Very Many Players

Vanilla stays vanilla

No recipes, no blocks, no gameplay changes. Multiplayer-safe, and your existing worlds open exactly as they were.

Streamline Master against Fabulously Optimized

Same world and seed, same viewpoint, Minecraft 26.2. Select a shot to open it full size and read the F3 overlay yourself.

+34% in this scene. Measured on a Ryzen 7 5700X with a Radeon RX 6600, deliberately headroom-rich hardware, so the difference reflects CPU and render overhead rather than a GPU bottleneck. On an integrated GPU the absolute numbers are far lower and the practical win shows up more as frame consistency than as peak FPS.

Every mod has a job

Each build resolves its own mod versions against Modrinth, so nothing is shimmed across game versions. The groups below describe the Minecraft 26.2 build.

Minecraft 26.3 adds Gnetum, Smart Particles, Entity View Distance, Ksyxis, Alternate Current, Fast Noise, Clumps, AudioThrottle, Raise Sound Limit Simplified, Async Logger, Force Close World Loading Screen and Quick Pack. It leaves out Chloride and Particle Core, which have no 26.3 build yet.

Before you install

  • Java 21 or newer. Required by Minecraft 1.20.5+. Modern launchers install it for you.
  • 3–4 GB allocated RAM. More is not better here; the pack is tuned to need less.
  • Install as a new instance. Updating an existing one in place leaves old config files behind, so the pack's tuning never applies.
